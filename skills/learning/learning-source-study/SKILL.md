# Source study

Turn a bounded source passage into an explanation the learner can use. Begin with the requested content, rather than testing material the learner has never encountered.

1. Locate the syllabus item, question or passage that defines the scope. Inspect the relevant source text and worked example before citing it. Give verified chapter or section references; distinguish PDF viewer pages from printed pages.
2. Explain the purpose and prerequisite idea, then develop one small concrete case. Connect the general rule to that case, including the conditions under which it applies. If useful, use an available `tech-explainer` skill for this responsibility.
3. Give a focused reading target and explain what to extract from it. If sources disagree, identify the disagreement and use an authoritative source to resolve it. If no suitable source is available, name that limitation and teach the bounded topic with explicit assumptions, or propose procuring a better source.
4. When practice fits the request, invite a prediction or [self-explanation](../learning-self-explanation/SKILL.md). For a new procedure, continue with [worked examples](../learning-worked-examples/SKILL.md). An explanation-only request ends after the explanation.

The result is an explanation with a checked source and precise reading target, or an explicitly identified source limitation and a bounded direct-teaching alternative. Reading completion alone does not establish assessed learning. If the learner already knows the material, use [retrieval](../learning-retrieval/SKILL.md) instead of repeating the lesson.

For a whole course, reuse `source-grounded-exam-tutoring` when available; it owns syllabus coverage and records. This skill owns one reading session.

Read [assessment](../learning-router/references/assessment.md) when checking understanding and [GATE adaptation](../learning-router/references/gate.md) for GATE. The [evidence reference](../learning-router/references/evidence.md) distinguishes source-verification choices from experimental learning findings.
