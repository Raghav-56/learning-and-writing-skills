# Retrieval

Make the learner produce the relevant knowledge before showing it. Select previously studied material and a prompt that tests the intended knowledge rather than recognition of a familiar wording.

1. Establish the target from the conversation or records. Ask for a definition with conditions, a derivation, a procedural step, or a short solution as appropriate. Keep the solution separate until the attempt or an explicit request for it.
2. Assess against a checked answer. Correct omissions and misconceptions, including a confident wrong answer. Use `answer-evaluator` when available. Reveal enough feedback to repair the gap; uncorrected guessing is not the goal.
3. Use one changed prompt when it will distinguish learning the idea from memorizing the answer. Choose [transfer](../learning-transfer/SKILL.md) for a genuine change of situation, and [error repair](../learning-error-repair/SKILL.md) for a consequential misconception.
4. Hand forgotten or effortful items to [spacing](../learning-spacing/SKILL.md) for later review. Return an assessed attempt and the specific gap, not a claim of permanent mastery.

If there is no prior exposure, give [source study](../learning-source-study/SKILL.md) or a worked example first. If a direct answer is requested, give it and mark that item solution-shown rather than independent. Confidence can help locate miscalibration but is optional; asking it on every item adds work.

Read [assessment](../learning-router/references/assessment.md) before marking and [GATE adaptation](../learning-router/references/gate.md) for GATE. [Research](../learning-router/references/evidence.md) supports retrieval broadly; it does not make every quiz equally useful.
