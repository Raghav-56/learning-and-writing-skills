# Assessment and continuity

Read this before assessing, recording or reporting learning progress. Reuse the course's existing rules and records; this reference adds evidence distinctions rather than another required course format.

## What the work establishes

Distinguish these observations in ordinary language:

- Explained or read: content was presented; independent performance is unassessed.
- Assisted: the learner used a hint, notes, an exposed step or a shown solution. State the assistance that matters.
- Independent: the learner supplied a defensible solution without that help on this item.
- Delayed: the learner returned after an actual recorded interval and retrieved or solved independently. If the interval is unknown, say so.
- Transfer: the learner handled a specified change of situation. State the change and help conditions rather than calling it general mastery.

Delayed and transfer are dimensions, not compulsory stages. A fresh independent success after an assisted example is useful evidence, while an immediate copied correction is not a second independent success. Successful self-explanation, recall and exam-speed execution test different capabilities.

Before giving a marked exercise, solve it and verify that its assumptions, intended answer and mark total agree. Judge the original question and all submitted working. If the available source or handwriting is unclear, state what is provisional. The agent's unchecked answer is not an authoritative key.

When scoring, preserve the original attempt and distinguish a marking correction from a later repair. Use official exam rules only when verified. A teaching rubric is labelled practice feedback. No fixed score or question count establishes mastery across topics. Ambitious rank goals require precision, not rank guarantees.

## State that helps the next session

First read the current conversation and the relevant existing course record. A quick explanation need not create files. If a sustained learning task authorizes records, update the course's existing location. Otherwise offer a compact handoff in chat; create a new record only when asked or when the task already includes persistent course tracking.

A useful minimal record identifies the topic and source, observed task, original outcome, help used, error or repair, and next review. Include the actual date or interval when known. Keep personal confidence separate from assessed correctness. Track unseen paper status when it affects exam calibration.

Keep records scoped to the learner and course. Global skill files hold the method, never a learner's scores or current question counter. Preserve unrelated records and newer learner updates. When a chat resumes, read its handoff before repeating a lesson; do not claim access to unavailable conversation history.

The learner may decline a quiz, ask for the solution, or stop. Honor that choice and record the narrow evidence available. Completion means the requested teaching or assessment task was handled, not that the learner was compelled to demonstrate mastery.
