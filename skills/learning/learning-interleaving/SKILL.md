# Interleaving

Train recognition of which method applies. Mix related problems that require meaningful choices after the learner has a usable foundation in each method.

1. Choose the strategies to discriminate and verify the learner has encountered them. A first exposure belongs in [worked examples](../learning-worked-examples/SKILL.md), not an unexplained mixed set.
2. Construct a manageable, unlabelled set. Solve every generated item and verify its assumptions and intended answer before presenting it, including unmarked general-learning practice. Vary the order without announcing the strategy before each question. Use question features that require selecting among methods, rather than cosmetic changes to one template.
3. Ask for a strategy choice and enough reasoning or working to check it. A correct calculation after the wrong justification may conceal a selection error. Separate strategy-selection errors from execution errors.
4. After the attempt, contrast the decisive cues and conditions. Send a specific gap to [error repair](../learning-error-repair/SKILL.md); return to the mixed set after a bounded repair. Use [transfer](../learning-transfer/SKILL.md) if a new situation is the remaining challenge.

For GATE, a set might mix appropriate algorithm choices or probability tools. Switching randomly among unrelated subjects is not the same intervention. Avoid assessing a method the learner has not been taught unless the task is explicitly diagnostic.

End with which methods the learner could distinguish and which cue remains unreliable. Read [assessment](../learning-router/references/assessment.md), [GATE adaptation](../learning-router/references/gate.md) when relevant, and [research](../learning-router/references/evidence.md) for the limits of interleaving findings.
