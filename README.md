# Learning and writing skills

Agent skills for studying, practising for GATE, and editing prose.

- [Learning skills](skills/learning/learning-router/SKILL.md). Start with the router for study planning or when you need help choosing a method. Its twelve methods cover tasks such as closed-book recall, worked examples, and timed exam practice.
- [Unslop](skills/unslop/SKILL.md). Edit prose to remove common AI writing patterns while preserving meaning and tone.

To install the learning suite, copy the skill folders inside `skills/learning/` into your agent's skills directory as siblings. Keep `learning-router/references/` with the router. To install Unslop, copy `skills/unslop/` into the same skills directory.
